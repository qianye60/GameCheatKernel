# 王者荣耀内存偏移文档

> 更新日期：2024年12月7日
> 测试环境：训练营模式（后羿 vs 敖隐）
> 游戏版本：当前最新版

---

## 一、基址获取

| 类型 | 获取方式 | 说明 |
|------|----------|------|
| libGameCore.so 基址 | `driver->getModuleBase("libGameCore.so")` | 每次启动变化 |
| libGameCore.so BSS | 解析 `/proc/pid/maps` 找 `[anon:.bss]` | 偏移入口地址 |

**重要**：本版本偏移从 **BSS 段** 开始，不是从模块基址开始！

---

## 二、完整偏移链

### 2.1 游戏管理器

```
BSS + 0x2728 → 游戏管理器指针
```

### 2.2 英雄列表

```
游戏管理器 + 0x8 → 英雄列表指针
```

### 2.3 英雄数组遍历

```
英雄列表 + i * 0x18 → 英雄数组项指针
英雄数组项 + 0x68 → 英雄对象指针
```

- `i` 范围：0-9（5v5最多10个英雄）
- 间隔：`0x18`（24字节）

### 2.4 英雄对象属性

| 偏移 | 类型 | 说明 |
|------|------|------|
| +0x30 | int | 英雄ID |
| +0x3C | int | 阵营（1=蓝方，2=红方） |
| +0x168 | ptr | 血量结构体指针 |
| +0x248 | ptr | 坐标指针链入口 |

### 2.5 血量结构

```
英雄对象 + 0x168 → 血量结构体指针
    +0xA8 → 当前血量 (int)
    +0xB0 → 最大血量 (int)
```

### 2.6 坐标指针链

```
英雄对象 + 0x248 → ptr1
    ptr1 + 0x10 → ptr2
        ptr2 + 0x0 → ptr3
            ptr3 + 0x60 → 坐标结构
                +0x0 → X坐标 (int)
                +0x8 → Y坐标 (int)
```

## 七、注意事项

1. **偏移会过期**：游戏版本更新后偏移可能变化
2. **必须在对局中**：游戏管理器指针只在对局中有效
3. **BSS vs Base**：本版本偏移从 BSS 段开始，不要用模块基址
4. **48位地址掩码**：读取指针后需要 `& 0xFFFFFFFFFFFF`
5. **地址有效性检查**：读取前应检查地址范围

## 八、代码示例

```cpp
// 初始化
uintptr_t bss = getBssAddress(pid, "libGameCore.so");

// 读取游戏管理器
uintptr_t gameManager = ReadPtr(bss + 0x2728);

// 读取英雄列表
uintptr_t heroList = ReadPtr(gameManager + 0x8);

// 遍历英雄
for (int i = 0; i < 10; i++) {
    uintptr_t entry = ReadPtr(heroList + i * 0x18);
    uintptr_t hero = ReadPtr(entry + 0x68);

    int id = ReadInt(hero + 0x30);
    int camp = ReadInt(hero + 0x3C);

    // 血量
    uintptr_t hpStruct = ReadPtr(hero + 0x168);
    int hp = ReadInt(hpStruct + 0xA8);
    int maxHp = ReadInt(hpStruct + 0xB0);

    // 坐标
    uintptr_t p1 = ReadPtr(hero + 0x248);
    uintptr_t p2 = ReadPtr(p1 + 0x10);
    uintptr_t p3 = ReadPtr(p2);
    uintptr_t coord = ReadPtr(p3 + 0x60);
    int x = ReadInt(coord);
    int y = ReadInt(coord + 0x8);
}
```
