# 王者荣耀内存偏移分析教程

> 本文档用于教育目的，分析游戏内存结构和偏移链原理

## 一、基础概念

### 1.1 什么是偏移？

偏移（Offset）是结构体内部成员相对于结构体起始地址的位置。

```cpp
class Hero {
    int type;           // +0x00 (偏移0)
    int padding;        // +0x04 (偏移4)
    long id;            // +0x08 (偏移8)
    float x;            // +0x10 (偏移16)
};

// 如果 Hero 对象地址是 0xA000
// 那么 id 的地址就是 0xA000 + 0x08 = 0xA008
```

### 1.2 基址 vs 指针 vs 偏移

| 类型 | 何时确定 | 何时变化 | 说明 |
|------|----------|----------|------|
| **基址(Base)** | 程序启动时 | 每次启动都可能不同(ASLR) | 如 `libGameCore.so` 的加载地址 |
| **指针值(Pointer)** | 运行时动态 | 每局游戏都不同 | 通过 read(地址) 读取得到 |
| **偏移(Offset)** | 编译时固定 | 游戏版本更新时 | 如 `+0x248`、`+0x168` |

### 1.3 为什么需要多级指针？

Unity/IL2CPP 游戏的对象是嵌套的组件模式：

```
Hero 对象
    │
    └─ Transform* 指针 ──► Transform 组件
                               │
                               └─ Data* 指针 ──► 实际坐标数据
```

每一层都是指针，需要逐级解引用才能到达最终数据。

## 二、偏移结构分析（天理源码版本）

### 2.1 基址获取

```cpp
// 获取模块基址和bss段地址
libGame_base = getModuleBase("libGameCore.so");        // 模块基址
lil2cpp_base = getbss("libGameCore.so:bss");           // bss段地址
```

### 2.2 第一级关键偏移

这是最重要的入口偏移，从基址开始：

```cpp
// 矩阵数据入口（用于世界坐标转屏幕坐标）
long temp = ReadValue(lil2cpp_base + 0x4712b8);

// 英雄数组入口（这是最关键的偏移）
long temp1 = ReadValue(libGame_base + 0x452E5C8);
```

### 2.3 英雄数组结构

```cpp
// 从 temp1 获取英雄相关数据
long bingxiang8 = ReadValue(ReadValue(temp1 + 0x48) + 0xD8);  // 自身英雄对象
long bingxiang1 = temp1 + 0x120;                               // 英雄列表基址

// 遍历英雄数组（最多10个英雄，5v5）
for (int i = 0; i < 10; i++) {
    // 每个英雄间隔 0x18 字节
    long bingxiang6 = ReadValue(ReadValue(bingxiang1 + i * 0x18) + 0x68);
    // bingxiang6 就是第 i 个英雄的对象地址
}
```

### 2.4 英雄对象内部偏移

从英雄对象 `bingxiang6` 可以读取以下数据：

```cpp
// 英雄ID
int heroId = ReadValue(bingxiang6 + 0x30);

// 阵营（1=蓝方，2=红方）
int camp = driver->read<int>(bingxiang6 + 0x3C);

// 血量结构
long hpStruct = ReadValue(bingxiang6 + 0x168);
int currentHp = driver->read<int>(hpStruct + 0xa8);  // 当前血量
int maxHp = driver->read<int>(hpStruct + 0xb0);      // 最大血量

// 视野数据
long viewStruct = ReadValue(ReadValue(bingxiang6 + 0x260) + 0x68);
int view = driver->read<int>(viewStruct + 0x18);  // 蓝方视野偏移
int view = driver->read<int>(viewStruct + 0x38);  // 红方视野偏移
```

### 2.5 坐标读取的完整偏移链（重点）

这是最复杂的偏移链：

```cpp
// 完整的坐标读取代码
long ptr1 = ReadValue(bingxiang6 + 0x248);   // 第1级
long ptr2 = ReadValue(ptr1 + 0x10);          // 第2级
long ptr3 = ReadValue(ptr2 + 0x0);           // 第3级（这里+0x0，直接读取）
long zuobiao = ReadValue(ptr3 + 0x60);       // 第4级，到达坐标结构

// 最终读取坐标
float x = driver->read<int>(zuobiao + 0x0);  // X坐标
float y = driver->read<int>(zuobiao + 0x8);  // Y坐标

// 简化写法（源码中的实际代码）
zuobiao = ReadValue(ReadValue(ReadValue(ReadValue(bingxiang6 + 0x248) + 0x10)) + 0x60);
float 坐标x = driver->read<int>(zuobiao + 0x0);
float 坐标y = driver->read<int>(zuobiao + 0x8);
```

**图示：**

```
bingxiang6 (英雄对象地址)
    │
    └─ +0x248 ──► [指针1]
                     │
                     └─ +0x10 ──► [指针2]
                                    │
                                    └─ +0x0 ──► [指针3]
                                                   │
                                                   └─ +0x60 ──► [坐标结构]
                                                                    │
                                                                    ├─ +0x0 ──► X坐标 (int)
                                                                    └─ +0x8 ──► Y坐标 (int)
```

## 四、BSS 段说明

### 什么是 BSS？

```
程序内存布局：

┌─────────────────┐ 高地址
│      栈 Stack    │  ← 局部变量（不稳定）
├─────────────────┤
│      堆 Heap     │  ← 动态分配（每次不同）
├─────────────────┤
│      BSS        │  ← 全局变量（稳定！）
├─────────────────┤
│      Data       │  ← 已初始化全局变量
├─────────────────┤
│      Code       │  ← 代码段
└─────────────────┘ 低地址
```

### 如何获取 BSS 地址

```cpp
// 通过 /proc/pid/maps 获取
uintptr_t getBssAddress(pid_t pid, const char* module_name) {
    char path[64];
    sprintf(path, "/proc/%d/maps", pid);
    FILE* fp = fopen(path, "r");

    char line[512];
    bool found = false;

    while (fgets(line, sizeof(line), fp)) {
        if (strstr(line, module_name)) {
            found = true;
            continue;
        }
        if (found && strstr(line, "[anon:.bss]")) {
            uintptr_t addr;
            sscanf(line, "%lx", &addr);
            return addr;
        }
    }
    return 0;
}
```

## 五、偏移查找方法

### 为什么偏移会失效？

游戏更新时，代码重新编译，结构体成员位置可能改变：

```cpp
// 旧版本
class Hero {
    int id;      // +0x00
    float hp;    // +0x04  ← 旧偏移
};

// 新版本（加了字段）
class Hero {
    int id;      // +0x00
    int newField;// +0x04  ← 新加的
    float hp;    // +0x08  ← 偏移变了！
};
```

### 查找方法

| 方法 | 思路 |
|------|------|
| **字符串定位** | 搜索特征字符串，找引用代码 |
| **函数Hook** | Hook关键函数，从参数获取地址 |
| **已知数据回溯** | 从已知值回溯指针链 |
| **对比分析** | 多局对比找稳定偏移 |

### 指针回溯步骤

```
1. 搜索已知值（如坐标）→ 找到存储地址
2. 搜索谁存了这个地址 → 找到上一级指针
3. 筛选：只保留 BSS 段范围内的地址
4. 计算相对于 BSS 的偏移
5. 换局验证偏移是否稳定
6. 重复直到回溯到 BSS 段
```

## 六、注意事项

1. **偏移版本依赖**：本文档中的偏移来自特定版本源码，游戏更新后会失效
2. **地址有效性检查**：读取指针前应检查地址是否有效
3. **48位地址掩码**：64位系统读取后需要 `& 0xFFFFFFFFFFFF`
